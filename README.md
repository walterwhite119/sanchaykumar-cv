# sanchaykumar-cv
Professional CV and portfolio of Sanchay Kumar Sivakumar

## Instagram bio link page

`index.html` is a mobile-first landing page that highlights the Co-Founder title —
made to be used as the single link in an Instagram bio.

### Customize it

Open `index.html` and update:

1. **Company name** — replace `Your Company` in the line marked `TODO`.
2. **Links** — replace the `#` placeholders in the `<nav class="links">` section
   with your company site, CV, and LinkedIn URLs.
3. **Photo (optional)** — swap the `SK` initials for an `<img>` tag
   (instructions are in the comment inside the avatar ring).

### Host it free with GitHub Pages

1. On GitHub, go to **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**, select the
   `main` branch and the `/ (root)` folder, then save.
3. Your page will be live at `https://walterwhite119.github.io/sanchaykumar-cv/`.
4. Paste that URL into your Instagram bio (**Edit profile → Links**).
